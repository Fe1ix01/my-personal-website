新电脑 / 网吧快速恢复

按顺序恢复 Windows 开发与外网环境。
01

v2rayN

先建立外网连接

v2rayN 国内加速入口 v2rayN 官方 GitHub
02

Git for Windows

用于拉取和提交 GitHub 项目

下载 Git
03

安装 Codex Desktop

通过 Codex App Manager 安装或更新 Codex 桌面版。

Codex App Manager

第三方开源安装/更新管理器，用于安装官方 Codex Desktop。

04

Node.js LTS

Codex CLI 需要时安装

下载 Node.js
05

安装 Codex CLI

npm install -g @openai/codex
06

恢复网站项目

cd %USERPROFILE%\Desktop git clone https://github.com/Fe1ix01/suze-os.git cd suze-os
07

GitHub 连接异常时

仅当 git clone 出现 Connection reset / timeout 时使用。

git config --global http.proxy http://127.0.0.1:10808 git config --global https.proxy http://127.0.0.1:10808

10808 是当前默认示例；如果本地代理端口不同，请修改端口。

08

启动 Codex CLI

cd %USERPROFILE%\Desktop\suze-os codex

推荐顺序：v2rayN → Git → Codex Desktop → Node.js（CLI 需要时）→ Codex CLI → clone Suze OS → 开始工作。
